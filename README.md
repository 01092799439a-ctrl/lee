# 여행사 업무관리 V1

## 실행
1. 저장소에서 index.html을 다운로드한다.
2. Chrome 또는 Edge로 연다. 설치나 API 키가 필요 없다.
3. 신규 업무에서 유형, 익명 번호, 마감일을 지정하고 업무 생성.
4. 실제 증빙을 확인하며 단계별 체크. 이전 단계를 해제하면 후속 완료도 해제된다.
5. 견적 계산 및 수배 요청 양식을 사용하고 실제 승인·예약은 공식 시스템에서 직접 처리한다.
6. 익명 JSON 백업 및 인쇄 기능을 이용한다. 백업 가져오기 기능은 아직 없다.

## 매일 업무
출근: 마감 초과 및 오늘 마감 확인 → 긴급 업무 우선 처리 → 신규 문의 등록 → 처리 증빙 검수 → 퇴근 전 진행 상태와 다음 조치 확인.
정기: 월 2일/9일/10일 전후/20일 비용 확인, 월말 장부와 영수증 대조, 계약·보험·인증서 만료 확인.

## 업무 분류
- 회사 운영: 계정 권한, 거래처, 법인 자격 및 갱신.
- 재무: 청구서·승인·입출금·영수증·장부·세무 검수.
- 중국 비자: 자격 확인, 서류, 온라인 심사, 결제, 센터 제출, 발급, 장부.
- 중국 단체 입국: 제도 유효성, 송객사, 명단, 승인, 귀국, 결과보고.
- 항공: 노선 및 운임, 승인, 입금, 재확인, 발권, 증빙.
- 전세기: 계약, 블록, TL, 모객, 반납, APIS, 정산.
- 투어: 접수, 가능성, 견적, 결제, 수배, 현장, 정산.
- 기타: KTX, 관광시설, 보험, 주차 및 결제.

## 보안 및 제한
공개 저장소용으로 원본의 인증정보, 거래처 연락처, 금융정보 및 고객자료를 제외했다. 로컬 저장은 암호화되지 않으며 브라우저 삭제 시 손실될 수 있다. 익명 번호만 사용한다. 실제 회사 데이터 사용 전 비공개 전환, 인증·권한·서버 DB·암호화·감사로그·백업 복구·보존기간 정책을 구축해야 한다. 외부 서비스 API 연결, 실시간 알림, OCR, 실제 발권·송금·신청 및 독립 AI 에이전트 실행은 미구현. 운영 전 테스트 필요. 인수인계서가 참조하는 OneNote, 계약서, 양식, 장부는 별도 확보 필요.
